# VanOs 固件（ESP32-S3 墨水屏阅读器）

read_pico 板（1216×684 墨水屏）固件，用于《文库本 VanOs》。

## 当前版本（2026-10-22 晚）

本轮把一整天的主线改动打包：**阅读背景、电量过低横幅、进度口径统一、行距与下划线、三键逻辑 v2**。

**阅读背景（新）**

- 图片放 `/sdcard/VanOS/BACKGROUND/`（.png / .jpg），阅读菜单 →「显示」→「阅读背景」里选
- **按书存**：每本书各记各的背景；同一张图被多本书选中时只烘一次帧（按文件名+大小+时间戳指纹共用）
- 「阅读留空」：开着时背景等比缩进正文区（四边完整、余白纯白），关掉时宽度拉满铺满整屏
- 设图时先把正文整章卸掉再烘图，峰值约 2.1 MB，不再出现「内存不足」

**电量过低横幅**

- 系统界面电量 5%、阅读页 4% 时弹一次底部横幅（全局模态，点「知道了」或 KEY2 关闭）
- 设置 →「关于本机」与 阅读菜单 →「显示」各有一个「电量提示」预览入口

**进度口径统一**

- 进度条、页脚、阅读历史三处统一同一口径；末页判据改用「这一页已排到本章末尾」
- 改字号 / 改文章图片档重排后写回重排前的锚点，反复切换不再累积后退

**行距与下划线**

- 行距四档 = 1.20 / 1.35 / 1.50 / 1.65 倍字号，出厂第 3 档
- 动态行高改成「档位下限保底」，不再把四档压成一档
- 下划线夹到字底 + 0.20em，不再压到下一行；末行不会越出版心
- 0 档页脚加宽，最后一行不再贴着进度条

**三键逻辑 v2**（完整映射见开发仓 `docs/KEYMAP.md`）

- KEY2 拆成短按 / 长按：短按 = 当前层的菜单或关闭，长按 = 整屏全刷
- 设置页的键盘光标导航整体删掉，设置页只用触摸操作
- 主页 KEY3 = 设置；书单 KEY1/KEY3 = 屏上左右翻页、KEY2 = 返回
- 阅读页：KEY2 短按开阅读菜单，菜单里 KEY1/KEY3 切分组，目录里 KEY1/KEY3 翻屏

**其它**

- 阅读页时钟每秒刷新（只在状态栏/页脚一条带内局部刷新），电量 30 分钟读一次
- 目录/书单底栏字号统一放大
- 发布版日志全静默（`ESP_LOG_NONE`）

## 刷机

**整片刷（推荐，第一次刷/对方是别的固件时）**：

```bash
esptool --chip esp32s3 -b 460800 --before default-reset --after hard-reset \
  write-flash --flash-mode dio --flash-freq 80m --flash-size 16MB \
  0x0 merged-binary.bin
```

**只刷应用（对方已经是 VanOs 固件时，快）**：

```bash
esptool --chip esp32s3 -b 460800 --before default-reset --after hard-reset \
  write-flash --flash-mode dio --flash-freq 80m --flash-size 16MB \
  0x10000 vanos-app.bin
```

## SD 卡要求

TF 卡（FAT32）根目录需要：

```
/sdcard/VanOS/fonts/朱雀仿宋.ttf   ← 必须，缺了没字
/sdcard/VanOS/BOOKS/*.epub         ← 书，可空
```

其余目录（`VanOS/`、`BOOKS/`、`EPUB_COVER/`、`fonts/`、`assets/fonts/`）首次启动自动创建。

```
/sdcard/pictures/*.png             ← 透明书封的源图（可选，自己放）
```

`/pictures/` 原本是官方固件的目录，VanOs 从 2026-10-19 起用它做**透明书封**的图源：
阅读菜单「显示 → 启用书封」会列出这个目录下的 `.png`，选一张之后按电源键进睡，
当前屏幕就会和它合成成关机图。书封按**每本书**记住，帧存在 `VanOS/.bkcover/`。
