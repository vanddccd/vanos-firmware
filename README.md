# VanOs 固件（ESP32-S3 墨水屏阅读器）

read_pico 板（小纸 Pico）固件，用于《文库本 VanOs》。

- 面板：E0470，1216×684，4bpp 16 灰，自研波形
- SoC：ESP32-S3（8MB PSRAM），ESP-IDF v6.1
- 电源管理：SY7636A（含 RTC）
- 触摸：CST836U（电容，只取第 1 点）
- 存储：TF 卡，FAT32

---

## 刷机

### 一、先判断该刷哪个

| 你现在的情况 | 刷哪个 |
|---|---|
| 新机、从没刷过、别的固件、开机黑屏/花屏 | **整片刷** `merged-binary.bin` |
| 已经是 VanOs，只是想要新版本 | **只刷应用** `vanos-app.bin`（快，约 1MB） |

两种都不会清除书库、阅读历史和设置（它们都在 TF 卡和 NVS 里）。

### 二、整片刷（推荐第一次）

```bash
esptool --chip esp32s3 -b 460800 --before default-reset --after hard-reset \
  write-flash --flash-mode dio --flash-freq 80m --flash-size 16MB \
  0x0 merged-binary.bin
```

`merged-binary.bin` 从地址 `0x0` 开始，包含：

| 偏移 | 内容 |
|---|---|
| `0x0` | bootloader |
| `0x8000` | 分区表 |
| `0x10000` | 应用（VanOs 本体） |
| `0xD10000` | ota_data（分区表里的 otadata 区） |

### 三、只刷应用（升级用）

```bash
esptool --chip esp32s3 -b 460800 --before default-reset --after hard-reset \
  write-flash --flash-mode dio --flash-freq 80m --flash-size 16MB \
  0x10000 vanos-app.bin
```

**应用分区起点是 `0x10000`**。日志里偶尔出现的 `0x17000`/`0x19000`/`0x1a2000` 是压缩数据的临时写入偏移，别照抄。

### 四、刷机注意

- **端口**：macOS `/dev/cu.usbmodem*`、Windows `COM*`、Linux `/dev/ttyACM*`；不确定就 `esptool chip-id` 挨个试
- **刷之前关掉串口监视器 / 抓日志的进程**，否则报 `Failed to open port` 或刷到一半断开
- 波特率 `460800` 稳定；刷完自动 `Hard reset`，画面几秒后出来
- 刷完没反应（黑屏 / 电脑认不到）：拔插一次 USB（ESP32-S3 的 USB-Serial-JTAG 偶尔掉线）
- 日志里的 `Wrote 4096 bytes at 0x001bb000` 这类小段是**差分刷写**，只写变化的扇区，属正常；只要后面出现 `Hash of data verified` 就是成功

## SD 卡要求

### 一、卡本身

- **FAT32** 格式（exFAT / NTFS 不认）
- 建议 8–32 GB，Class 10 以上；容量特别大（64GB+）的卡个别初始化慢
- 没插卡也能开机进系统，但书库、字体、书封、阅读背景全部不可用

### 二、目录结构

固件会自己建目录，你只需要往里放文件：

```
/sdcard/
├── pictures/                    ← 透明书封的源图（自己放）
│   ├── 书封1.png
│   └── 书封2.png
└── VanOS/
    ├── BOOKS/                   ← 书（自己放）
    │   ├── 某本书.epub
    │   └── 另一本.epub
    ├── fonts/                   ← 正文字体（自己放，强烈建议）
    │   └── 朱雀仿宋.ttf
    ├── assets/fonts/            ← 字体备用路径（同名字体放这里也认）
    ├── BACKGROUND/              ← 阅读背景图（自己放）
    │   ├── 纸纹.png
    │   └── 旧照片.jpg
    ├── EPUB_COVER/              ← 自动：从书里抽出的封面
    ├── .bkcover/                ← 自动：书封帧缓存
    ├── .readbg/                 ← 自动：阅读背景帧缓存
    ├── LIBRARY.json             ← 自动：书库索引
    ├── HISTORY.json             ← 自动：阅读历史
    └── BOOKMARKS.json           ← 自动：书签
```

### 三、每个目录 / 文件的要求

| 路径 | 放什么 | 格式要求 | 说明 |
|---|---|---|---|
| `VanOS/BOOKS/` | 电子书 | `.epub`（只认 EPUB，TXT 不支持） | 文件名就是书名；放进去后在书单页刷新，会出现在 `LIBRARY.json` |
| `VanOS/fonts/朱雀仿宋.ttf` | 正文字体 | `.ttf`，文件名必须是「朱雀仿宋.ttf」 | 缺了会退回固件内置子集：常见字能显示，**生僻字会缺**；强烈建议放 |
| `VanOS/assets/fonts/` | 同上 | 同上 | 备用查找路径，`fonts/` 里找不到才来这里 |
| `pictures/` | 书封源图 | `.png`（透明底最好） | 阅读菜单「显示 → 启用书封」列出这里的 PNG；选中后按电源键进睡，用当前画面与这张图合成关机图。**按书记住** |
| `VanOS/BACKGROUND/` | 阅读背景 | `.png` / `.jpg` | 阅读菜单「显示 → 阅读背景」列出这里的图。**按书记住**；多本书选同一张只烘一次 |
| `VanOS/EPUB_COVER/` | 自动 | — | 不用管，扫描书时会从 EPUB 里抽封面 |
| `VanOS/.bkcover/`、`VanOS/.readbg/` | 自动 | — | 烘好的 4bpp 帧缓存。删了会重新烘（下次用会慢几秒），平时别动 |
| `VanOS/LIBRARY.json` | 自动 | — | 书库索引。只由扫描产生，手改会被覆盖 |
| `VanOS/HISTORY.json` | 自动 | — | 阅读历史。只有真正打开过的书才有条目 |
| `VanOS/BOOKMARKS.json` | 自动 | — | 书签 |

图片尺寸建议：

- **阅读背景**：建议 684×1216 或同比例（540×960、1080×1920 都可以）。开「阅读留空」时整图缩进正文区、四边完整；不开时宽度拉满铺满整屏（上下可能被裁）
- **书封**：任意比例都行（按宽度铺满、上下留白），建议至少 400×600 像素；带透明通道的 PNG 能和界面合成
- 单张图建议 **小于 6 MB**，太大内存吃紧

### 四、缺了会怎样

| 缺什么 | 后果 |
|---|---|
| 没插卡 | 能开机，但书库空、字体退内置子集、书封 / 背景不可用 |
| `VanOS/BOOKS/` 里没书 | 书单页空 |
| 没字体 | 常见字正常，生僻字显示成缺字方块 |
| 没 `pictures/` | 书封弹窗是空列表 |
| 没 `VanOS/BACKGROUND/` | 阅读背景弹窗是空列表 |
| 删掉 `LIBRARY.json` | 下次开机重新扫描重建（阅读历史不受影响） |
| 删掉 `HISTORY.json` | 阅读历史清零（书还在） |

### 五、换卡 / 清空

- **换卡**：新卡按上面建目录放文件即可；`LIBRARY.json` / `HISTORY.json` 可以整个拷过去
- **清空记录**：设置 →「清空阅读记录」，会清掉书库索引、阅读历史、书签，以及阅读背景的缓存帧（书封缓存不动）
- **别手改 JSON**：书库索引由扫描重建；阅读历史只有真的读过书才会写

## 更新日志

### 2026-10-24

**传书**

- 断点续传：暂停或断网后，继续时从设备已收到的位置续传，不用从头传
- 断线自动重试 3 次（每次重试前向设备要真实偏移）
- 接收缓冲 16KB → 32KB，弱网更稳
- 修上传文件名编码校验：此前 `%ff`、`%C0%AF` 这类非法 UTF-8 文件名可绕过校验
- 修「续传多次后卡在『等待设备保存』」：上传成功分支漏把状态从 UPLOADING 收回 READY

**Wi-Fi**

- 校时页 60s 内复用扫描结果，不再每次进页都重扫
- 校时连接：每个网络最多等 10s，超时自动换下一个
- 校时用省电模式，传书用满速模式
- 选网弹窗加「清除已保存网络」
- 校时完成 / 退出传书页后自动关 WiFi、释放内存；浅睡锁屏前暂停传书服务，醒来恢复

**联网校时页**

- 显示已连接客户端数量 / IP / 信号强度
- 时间每秒刷新；二维码 240 居中
- 长 SSID / IP 自动截断，不越界

**USB 读卡模式（新）**

- 设置 → 存储 →「USB 模式」：开 = 卸载本机 FAT，把 TF 卡作为 USB 大容量存储交给电脑（设备名 `Read Pico SD`）；关 = 断开主机、重挂本机 FAT。开关状态不落盘，开机永远是关。
- 进入前停传书服务、放掉封面缓存、SD 字体切内建并挂起；退出时 `tud_disconnect` → 重试释放 MSC → 归还内部 USB PHY 给 USB-Serial/JTAG（电脑能再次识别串口与刷写）→ 重新挂载并恢复字体。
- USB 模式下锁死输入：只有「USB 模式」那一行可点，三键失效，不翻页、不锁屏、不浅睡/深睡。
- 移植自上游 kiikoread rc99，`components/espressif__esp_tinyusb/` 整目录引入。

**章节标题识别**

- 首部全角空格（「　第六章」）、号名同块（「第六章 大漠」）、全角分隔符（「第6章：黑暗」）、中文/阿拉伯数字混用（第六章 vs 第6章）—— 之前这些书会「多插一个虚拟标题、原文还在」，现在能原位替换。
- 书前有封面/书名页/版权页时也能找到标题块（搜索范围 4 → 8 块）。
- 纯号章（只有「第六章」）走章名行大字样式。

**章节样式**

- 1 档竖条按字形墨迹中心对齐；2/3 档段后距放宽；3 档竖条加粗。

**目录 / 书签**

- 底栏改单一容器两行：上页码、下「返回阅读」，点容器任意处都返回；页码水平/垂直都真正居中。
- 目录 11 行；箭头槽拆半：内半翻 1 页、外半跳 5 页（clamp 到首/末页），首/末页隐藏对应外侧半。
- 书签页共用同一页码绘制，不足一屏不显示；书签增删后自动夹取页码。

**注脚**

- 弹层固定格式：字号字体跟正文、首行缩进 2 字（按实测字宽）、行距 1.5em、字距 0、左对齐。
- 长注脚卡片内上下滑动 + 右侧滚动条 + 底部「…（上下滑动查看更多）」提示。

**排版**

- 首行缩进修正：0/1/2/3 档 = 0/1/2/3 个中文字（此前 1 档缩进 10 个字）；51/52/55/56 字号下首行第 1 字偏左 1~4px 的问题解决。
- 字距档 0~3 放宽到 0.05/0.10/0.15em，差异明显。
- 字号弹窗里改完字号，关掉菜单正文立刻生效（此前要翻页才触发）。

**EPUB 解码修复**

- `resolve_path` 不再拒绝含 `:` 的条目名：部分 EPUB 把资源名混淆成 `Text/_**::*:*.xhtml` 这类带冒号/星号的名字，此前一律判成路径穿越、整本书打不开（《废都》实测 `package_parse err 0x102`）。
- `zip_open` 的解压上限改为只限「压缩后 packed」大小：此前按 `unpacked ≤ 4 MB` 拒绝条目，《鬼吹灯全集》里的中文字体（unpacked 4.06 MB / packed 2.7 MB）直接把整本书挡在门外（`zip_open err 0x104`）。现在按调用方 cap 判，解压后的实际大小仍由 `zip_extract` 兜底。
- `rd_chap_parse` 全角标点剥离循环补 `c1 == 0` 守卫（原逻辑在串尾会越界读 1 字节，UB）。

**其它**

- 首页「全部 →」热区加大，减少误触
- 传书 HTTP 服务启动顺序修复：此前可能先起服务再起 WiFi，点「开始传书」偶发网络连接失败
